# User Stories — detail

> Full detail for **Ready and beyond** stories, grouped by state. Written here by `/detail-us`; each entry's heading is its **bare ID** (stable `#id` anchor) with the title on the line below; the
> matching one-line index lives under each story's epic in `Epic-Backlog.md`. State is shown by which group a
> story sits in; it moves only via commands (`/plan-sprint`, `/done-us`, `/close-sprint`). The fine board
> column (To Do→In PR) while In Sprint lives in `Sprint.md`.
>
> 📝 Draft stories are **not** here — until detailed they exist only as an index line in `Epic-Backlog.md`.
